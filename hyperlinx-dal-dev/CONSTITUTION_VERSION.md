## Purpose

This file versions the StellaOS Constitution independently from application software releases.

The Constitution is the governing framework.

The codebase is one implementation of that framework.

## Versioning Rule

Constitution versions change only when constitutional authority, doctrine hierarchy, or governing principles change.

Application releases may occur without changing the Constitution version.

Implementation details shall not force a Constitution version change unless they reveal a required constitutional amendment.

## Runtime Execution Policy

1. Constitutional assembly engines must execute only from an assembly command, persisted draft package load, or explicit refresh.
2. React render must consume immutable projection artifacts and shallow summaries.
3. Every generated runtime artifact needs a stable hash or revision id.
4. Background jobs must write status, input hash, output artifact id, duration, and invalidation reason.
5. UI memoization is a short-term guard; persistent runtime caches are the durable solution.

# ARTIFACT_LINEAGE

Date: 2026-07-03

## Purpose

Artifact Lineage records which constitutional artifacts produced another artifact.

## Examples

Draft IOF Package may be produced from:

- Product Doctrine
- Commercial Audit Projection
- Audit Object Manifest
- Address Projection
- PD-003 Production Projection

Engineering Projection may be produced from:

- Draft IOF Package
- Kernel Execution Graph

## ScopeVersion Readiness

ScopeVersion promotion can later inherit this lineage without recomputing the source artifact chain.
